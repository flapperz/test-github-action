# Frontend (React + TypeScript + Vite)

A Vite React TypeScript application.

## Setup

```bash
npm install
```

## Run

```bash
npm run dev
```

## Linting

```bash
# Type check
npm run type-check

# Lint
npm run lint

# Check formatting
npm run format:check

# Format code
npm run format
```

## Build

```bash
npm run build
```
