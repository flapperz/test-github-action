# Frontend (React + TypeScript + Vite)

A Vite React TypeScript application.

## Setup

```bash
yarn install
```

## Run

```bash
yarn run dev
```

## Linting

```bash
# Type check
yarn run type-check

# Lint
yarn run lint

# Check formatting
yarn run format:check

# Format code
yarn run format
```

## Build

```bash
yarn run build
```
